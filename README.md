# Time Sum для Obsidian

Простой плагин для Obsidian, который вычисляет сумму временных интервалов в заметке.

## Как это работает

Плагин сканирует вашу заметку на наличие временных интервалов, указанных в формате `(1w 2d 3h 4m)`, и суммирует их. Результат отображается в специальном блоке кода.

## Возможности

-   Автоматический подсчет времени в заметке.
-   Поддержка недель (`w`), дней (`d`), часов (`h`) и минут (`m`).
-   Суммирование всех найденных интервалов и отображение в удобном формате.
-   Команда для принудительного обновления подсчета.

## Использование

1.  Создайте блок кода с типом `time-sum` в том месте, где вы хотите видеть результат.
2.  Добавляйте временные интервалы в любом месте вашей заметки, заключая их в круглые скобки. Например: `(2d 4h)`, `(1w)` или `(30m)`.

Плагин автоматически найдет все интервалы, просуммирует их и выведет итоговое время в блоке `time-sum`.

### Формат вывода

Итоговое время отображается в днях, часах и минутах (`d`, `h`, `m`). Например, `3d 5h 30m`.

### Пример

```markdown
# План проекта "Альфа"

- Анализ требований (1d 4h)
- Разработка архитектуры (3d)
- Написание кода для модуля A (5d 2h 30m)
- Тестирование (1w)
- Совещания и обсуждения (4h 15m) + (1h)

## Итоговое время

` ```time-sum
` ```
```

В режиме чтения (Reading view) блок `time-sum` автоматически покажет суммарное время.

## Команды

-   **Sum time durations**: Принудительно запускает подсчет времени для текущей заметки. Полезно, если вы хотите обновить сумму в режиме редактирования.

## Установка

### Через Community Plugins (рекомендуемый способ)

1.  Откройте **Настройки** в Obsidian.
2.  Перейдите во вкладку **Community Plugins**.
3.  Убедитесь, что "Restricted mode" **выключен**.
4.  Нажмите **Browse** и найдите плагин "Time Sum".
5.  Нажмите **Install**, а затем **Enable**.

*Примечание: Этот способ будет доступен после публикации плагина в официальном каталоге.*

### Через BRAT (для бета-тестирования)

1.  Установите плагин BRAT из официального магазина плагинов Obsidian.
2.  Откройте настройки BRAT (в разделе "Сторонние плагины").
3.  Нажмите **Add Beta plugin**.
4.  Вставьте URL этого репозитория: `https://github.com/dstarod/obsidian-time-sum`.
5.  Нажмите **Add Plugin**. BRAT установит плагин.
6.  Включите плагин "Time Sum" в разделе "Сторонние плагины".

### Вручную

1.  Создайте папку `time-sum` в директории плагинов вашего хранилища (`<VAULT_ROOT>/.obsidian/plugins/`).
2.  Скачайте последнюю версию плагина со страницы релизов на GitHub.
3.  Скопируйте файлы `main.js`, `manifest.json` и `styles.css` (если он есть) в созданную папку (`<VAULT_ROOT>/.obsidian/plugins/time-sum/`).
4.  Перезапустите Obsidian.
5.  Перейдите в «Настройки» -> «Сторонние плагины» и включите "Time Sum".
